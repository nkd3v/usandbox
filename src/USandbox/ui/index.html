Run a program in a throwaway account

usandbox creates a hidden standard user, runs the program as that user, watches its network traffic, and deletes the account and its profile when the program exits.

usandbox makes a new certificate authority for each run. Only the throwaway account trusts it, its private key stays in memory, and it is deleted with the account. Nothing is added to your account's or the machine's certificate stores.
